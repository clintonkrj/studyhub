# orbit. – IBW Studienplaner

Studienorganisation für **Internationale Betriebswirtschaft (B.A.) an der Hochschule Aalen** mit sieben Semestern, farbigem Wochenstundenplan, Aufgaben, Klausuren, Lernzetteln und Karteikarten, Noten, Timer und Studienplanung.

## Webseite

Nach Aktivierung von **Settings → Pages → Deploy from a branch → main → /(root)**:
https://clintonkrj.github.io/studyhub/

## Daten

Aufgaben, Notizen und Termine werden im Browser gespeichert. **Einstellungen → Sicherung exportieren** erstellt ein JSON-Backup, das auf anderen Geräten importiert werden kann. Es gibt keine automatische geräteübergreifende Synchronisierung.

## Stundenplan

Die Datei `data/stundenplan.ics` ist ein importierter Stand des sPlan-Kalenders fürs 1. Semester WS 2026/27. In den Einstellungen kann eine neue `.ics` importiert werden. Für folgende Semester muss ein neuer Hochschulkalender importiert werden.

Offizielle iCal-Quelle: https://vorlesungen.htw-aalen.de/splan/ical?lan=de&puid=54&type=pg&pgid=14700

## Hinweise

Klausurtermine sind bewusst nicht vorausgefüllt. Der Notendurchschnitt ist eine vereinfachte CP-gewichtete Anzeige und nicht automatisch die offizielle Berechnung nach Prüfungsordnung.

Entwickelt als eigenständige statische Web-App (HTML, CSS, JavaScript) ohne Serverpflicht für persönliche Daten.
